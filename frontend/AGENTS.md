# Frontend - Codex Instructions

React 19 SPA using TanStack Router and Query, a tRPC v11 client, optional OIDC authentication,
Tailwind 4, Vite 7, Vitest, and React Testing Library.

## Commands

Run from `frontend/` with **npm** because this workspace owns `package-lock.json`:

- `npm run dev` serves on `0.0.0.0:52080`.
- `npm run build`, `npm run typecheck`, `npm run lint`, and `npm run test` are the focused checks.
- `npm run build:docker` uses relaxed compiler settings; it is not a substitute for typechecking.

## Architecture

Startup is `loadConfig()` -> `initTrpcClient()` -> providers -> router. `AuthProvider` and
`AuthGuard` wrap the router root, not `main.tsx`. Import `AppRouter` as a type from the backend;
the frontend has no API code generation.

Create file-based routes in `src/routes/` with `createFileRoute`. Dotted names become URL
segments and `$id` denotes a parameter. `src/routeTree.gen.ts` is generated by the router
plugin and must never be edited.

Runtime `public/config.json` takes precedence over build-time `VITE_*` configuration. OIDC is
enabled only when an authority is configured. Authentication includes both the library store and
a manual localStorage fallback; account for both when changing token behavior. Tailwind is
CSS-first in `src/index.css` and dark mode is class-based.
