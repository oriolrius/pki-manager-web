# Documentation

This folder is the source of the documentation. Read it on the website, where it has
navigation, search and the API reference:

**<https://pki-manager.oriolrius.cat/>**

| Folder | Content |
|---|---|
| `about.md`, `how-it-works.md`, `features/` | What PKI Manager is and does (product pages) |
| `get-started/`, `guides/`, `ssh/`, `operations/`, `api/` | Install, use and operate |
| `development/` | Develop PKI Manager |
| `diagrams/` | PlantUML sources of the diagrams |

One rule: the URL of a page is its path in this folder (`guides/private-ca.md` is
`/guides/private-ca/`). The other rules, and where every other document lives, are in
[How the docs are organised](development/documentation.md).
